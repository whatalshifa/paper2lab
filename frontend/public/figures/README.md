# Sample paper figures

The figures of the two sample papers, cut from their PDFs by the API (`GET /api/papers/{id}/figures/{figure}.png`) and saved here, so they show at once even while the free API server is asleep. The reader tries these first and falls back to the API (`FigureCard.tsx`).

If a sample's figure positions in `backend/app/samples/*.json` change, download the new pictures from the live site's figure URLs and replace these files.
